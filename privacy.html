最終更新日：2026年10月22日

本ポリシーは、琉亜きらんが運営する Kiran YouTube Analyticsにおける GoogleおよびYouTubeデータの取り扱いを説明します。

1. 利用目的

本アプリは、YouTubeチャンネルの成長分析、 動画・ライブ配信の成果比較、コンテンツ改善のために データを利用します。

2. 取得する情報

YouTube Data APIを通じて、チャンネル情報、 公開動画情報、再生回数、登録者数などを取得します。

チャンネル所有者の許可を得た場合、 YouTube Analytics APIから再生時間、 平均視聴時間、登録者の増減、動画別の分析指標を 読み取り専用の権限で取得します。

3. データの利用・保存

取得した情報はチャンネル運営の分析と ダッシュボード表示に使用します。

集計データはGitHubの管理するリポジトリに JSON形式で保存します。認証に必要な秘密情報は、 GitHub Actions Secretsなどの 非公開設定で管理します。

集計データには、公開動画情報に加えて チャンネル所有者の許可を得た分析指標が 含まれる場合があります。

4. 情報の共有

取得したGoogleユーザーデータを広告目的で 第三者へ販売することはありません。

データの保存・処理にはGitHub、 ダッシュボード表示にはStreamlitなどの サービスを利用します。

所有者向け分析情報の公開範囲は、 利用するリポジトリとダッシュボードの アクセス設定によって異なります。

5. 認証とセキュリティ

Google OAuthによって所有者からアクセス許可を 取得します。Googleアカウントのパスワードを アプリが取得することはありません。

不要になったアクセス権限は、 Googleアカウントのセキュリティ設定から 取り消すことができます。

6. 保存データの削除

保存データの削除を希望する場合は、 以下の連絡先から申請できます。

本人確認後、対象データの保存場所を確認し、 適用される規約に従って削除に対応します。

本アプリで保存データを削除しても、 YouTube本体のデータは削除されません。
